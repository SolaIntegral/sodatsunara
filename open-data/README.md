# オープンデータ

このフォルダには、アプリケーションで使用するオープンデータファイルを格納しています。

## フォルダ構造

```
open-data/
├── csv/          # CSV形式のデータファイル
├── xls/          # Excel形式のデータファイル
├── json/         # JSON形式のデータファイル
├── processed/    # 処理済みデータファイル
└── README.md     # このファイル
```

## データの種類

### CSV フォルダ
- 市町村の統計データ
- 人口統計
- 経済指標
- その他の構造化データ

### XLS フォルダ
- Excel形式の統計データ
- 複数シートを含むデータ
- グラフや図表を含むデータ

### JSON フォルダ
- APIから取得したデータ
- 構造化されたJSON形式のデータ
- 設定ファイルやメタデータ

### Processed フォルダ
- アプリケーション用に加工されたデータ
- 正規化されたデータ
- インデックス化されたデータ

## データの利用方法

1. 生データは各形式フォルダに保存
2. アプリケーション用に加工が必要な場合は、`processed/`フォルダに保存
3. データの更新時は、元データと処理済みデータの両方を更新

## 注意事項

- データファイルは適切な命名規則に従って保存してください
- 大きなファイルの場合は、圧縮形式での保存を検討してください
- データの出典や更新日時を記録してください
