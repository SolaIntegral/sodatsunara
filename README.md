# そだつなら (Sodatsunara) Platform

習志野市内の中小企業・個人商店の売上向上を支援する地域経済循環型ビジネス支援プラットフォーム

## 概要

「そだつなら」は、習志野市内の事業者と市民をつなぐプラットフォームです。オープンデータを活用した地域発見機能を新たに追加しました。

### 主な機能

- **市民向け機能**: 求人検索、企業情報閲覧、メッセージング
- **企業向け機能**: ダッシュボード、求人掲載、地域データ分析、マーケティング支援
- **🆕 地域発見機能**: お店マップ、おすすめスポット、オープンデータ活用

### 新機能: 習志野市を発見

習志野市のオープンデータを活用して、市内のお店マップとおすすめスポット機能を実装しました。

#### 実装した機能
- **お店マップ**: インタラクティブな地図で市内の店舗を表示
- **おすすめ機能**: スコアリングシステムによるおすすめ店舗の表示
- **検索・フィルタ**: 店舗名・住所での検索、カテゴリ別フィルタリング
- **レスポンシブデザイン**: モバイル・タブレット・デスクトップ対応

#### 活用したオープンデータ
- 習志野市文化施設データ（XLS形式）
- 6つの文化施設情報（習志野市民会館、習志野文化ホール等）
- 緯度経度情報、住所、電話番号等の詳細データ

## セットアップ

### 1. 環境変数の設定

`.env.example` を `.env.local` にコピーし、Firebase の設定値を入力してください。

\`\`\`bash
cp .env.example .env.local
\`\`\`

### 2. 開発環境での実行

\`\`\`bash
npm install
npm run dev
\`\`\`

### 3. Docker での実行

\`\`\`bash
# ビルド
docker-compose build

# 実行
docker-compose up -d
\`\`\`

## Firebase セットアップ

1. Firebase Console でプロジェクトを作成
2. Authentication, Firestore Database, Storage を有効化
3. Web アプリを追加し、設定値を `.env.local` に設定

## デプロイ

Docker を使用してデプロイできます。`docker-compose.yml` を使用して本番環境にデプロイしてください。

## 新機能のデモ

### 1. 地域発見機能の確認
```bash
# 開発サーバーを起動
npm run dev

# ブラウザで http://localhost:3000 にアクセス
# 「習志野市を発見」ボタンをクリック
```

### 2. 主要機能
- **おすすめタブ**: カード形式で店舗を表示、カテゴリフィルタリング
- **マップタブ**: 地図上で店舗を表示、インタラクティブな操作
- **検索機能**: 店舗名・住所での検索
- **詳細表示**: 店舗の詳細情報をモーダルで表示
